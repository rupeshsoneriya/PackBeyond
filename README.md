# Print X — Next.js Website

A pixel-close recreation of the provided Print X Webflow template screenshots, built with Next.js 15 (App Router), TypeScript, and Tailwind CSS v4.

## Pages
- `/` — Home
- `/about` — About
- `/services` — Services
- `/products` — Products

## Getting started

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Notes
- All images are placeholders (via placehold.co). Swap the `src` values in each page/component with your real product photography and lifestyle shots.
- Colors, spacing, and copy live directly in each page file — search for the Lorem ipsum text to replace with real copy.
- Brand color is set in `app/globals.css` (`--brand: #4f6bf6`) — change it there to re-theme the whole site.
- Social icons in the footer are placeholder text badges (f / ig / in / yt) since brand logo icons aren't bundled with the icon library — swap in your own SVGs if needed.
